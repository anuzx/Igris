## 📦 Installation 
```bash
git clone https://github.com/anuzx/Igris.git
cd Igris 
bun install 
bun link  
```

##  ⚙️ Setup
**Step 1. Get a free OpenRouter key**

Visit [https://openrouter.ai/](https://openrouter.ai/). , To get the Api key

**Step 2. Add it to your project's .env**

```bash
OPENROUTER_API_KEY="your_key_here"
OPENROUTER_DEFAULT_MODE=openrouter/free
```

**Step 3. Launch Igris**

```bash
igris arise
```
